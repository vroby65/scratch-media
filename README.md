# Scratch Media Archive

This repository contains a collection of media assets for Scratch, including:

- Sprites
- Costumes
- Backgrounds
- Sounds

Many of these assets were removed from the current version of Scratch 3. Others were created by me, and I hope more will be contributed by the community.

All files are organized into folders by type.

Feel free to use, modify, and share these resources in your Scratch projects!

## Contributions

Contributions are welcome! If you have original or classic Scratch media you'd like to share, please open a pull request.
